# mod-twink-vendor
**Azerothcore module** — A permanent vendor that sells scaled raid gear specifically for twink brackets (19, 29, 39, 49, 59, 69, 79).

## Features
- 📦 Creates **new item copies only** (original database items are untouched)
- 🎯 7 twink brackets with balanced scaling (stats, item level, required level)
- 🛒 One easy-to-place permanent vendor NPC
- ⚡ GM command: `.twinkraidloot spawn`
- 🔧 Fully configurable scaling multipliers and prices
- ✨ Clean item names like `[19] Thunderfury` or `[69] Atiesh`
- 🔗 Works perfectly alongside `mod-autobalance` and `mod-raid-loot-expansion`

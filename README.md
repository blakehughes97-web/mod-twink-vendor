\# mod-twink-raid-loot



\*\*Official AzerothCore module\*\* — A permanent vendor that sells \*\*scaled raid gear\*\* specifically for twink brackets (19, 29, 39, 49, 59, 69, 79).



This is a \*\*completely separate module\*\* from `mod-raid-loot-expansion`. It does \*\*not\*\* affect normal raid loot drops — it only adds a vendor where players can \*\*buy\*\* pre-scaled versions of raid items for their twink characters.



\## Features

\- Creates \*\*new item copies only\*\* (original database items are untouched)

\- 7 twink brackets with balanced scaling (stats, item level, required level)

\- One easy-to-place permanent vendor NPC

\- GM command: `.twinkraidloot spawn` (places the vendor anywhere in the world)

\- Fully configurable scaling multipliers and prices

\- Clean item names like `\[19] Thunderfury` or `\[69] Atiesh`

\- Works perfectly alongside `mod-autobalance` and `mod-raid-loot-expansion`

\-.twinkraidloot spawnSpawns (and saves) the twink vendor NPC
